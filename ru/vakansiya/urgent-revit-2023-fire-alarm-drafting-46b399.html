Urgent Revit 2023 Fire alarm Drafting

  • Freelancer.com
  • Remote
  • 1500–12500 INR
  • Дата: 2026-11-14
Дата объявления14.11.2026

Freelance layihə · Excel, CAD/CAM, Electrical Engineering, AutoCAD, Drafting, Revit

I have fifty DWG drawings that need to live in a single Revit 2023 project file. Your task is straightforward: trace clean 2D polylines for every wire route, tag each device, set up drawing sheets, and generate basic schedules. Most of the information is already on the DWGs; I will also supply a separate device list so you can cross-check and fill any gaps. I will be on hand for technical questions, but I’m looking for someone who can focus full-time on this for one week and deliver a well-organized .RVT file ready for my review. By the end of the week I expect: • One Revit 2023 file containing all 50 imported DWGs • Accurate polyline wire routes and device tags throughout • Sheets laid out and numbered to match the original drawings • Basic schedules pulling data from both the DWGs and my device list If you are available immediately and comfortable working solely in Revit 2023, let’s get started.
